02 / THE METHOD AS A REUSABLE ASSET

Report a failed boundary as clearly as a passing one.

A public testing discipline can be adopted without running PayGod. The published attack catalogue was frozen before the implementation it evaluates.

FREEZE FIRST

Precommitted tests

Specify the adversarial action and expected result before execution; avoid retrospective score changes.

Attack catalogue ↗
FOUR OUTCOMES

Do not launder harness errors

REJECTED_AS_EXPECTED, BYPASS_OBSERVED, NOT_TESTABLE_UNDER_T0, HARNESS_DEFECT. A harness defect is never a security pass.

KNOW THE SOURCE

Classify every claim

SOURCE_PROVEN, DOC_CLAIMED, RUNTIME_OBSERVED and UNKNOWN. Show evidence links and the trust-root owner.

NON-CLAIM WITNESS

Coherent forgery remains possible

An entirely rewritten but internally consistent bundle may pass integrity checks. A separately supplied receipt commitment can detect substitution.

Verification challenge ↗
Integrity ≠ authenticity. Signature ≠ permission. An admitted fact ≠ a correct decision. A decision ≠ authorized downstream execution.
Claim ceiling: No bypass was observed under Threat Model T0 across the declared enforcement surfaces of the controlled local harness. This is not a claim of universal non-bypassability, independent institutional endorsement, or verified economic value.
